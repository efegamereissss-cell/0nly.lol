# 0NLY.LOL - Ultra-Elite Identity & Bio Platform

VIP sanalcılar, oyuncular ve roleplay toplulukları için sıfırdan tasarlanmış prestijli bio-link platformu.

## 🚀 Özellikler
- **Dinamik Stüdyo Suite (`#/profilecreate`)**: Canlı 3D kart önizlemesiyle profil oluşturma.
- **Dinamik URL Yönlendirmesi**: `0nly.lol/{username}` kişiye özel bağlantılar.
- **7 Özel Tema**: Obsidian Black, Midnight Violet, Cyber Magenta, Miami Cyan, Blood Crimson, Royal Gold, Matrix Emerald.
- **3D Fare Eğim Fiziği (Interactive 3D Tilt)**
- **Discord Canlı Aktivite (Rich Presence)**
- **Rozetler & Özel Avatar Çerçeveleri**
- **Vercel Uyumlu**: Sıfır konfigürasyon, statik web altyapısı.

## 🛠️ Kurulum & Dağıtım
Bu proje saf HTML5, CSS3 ve JavaScript (ES6) ile yazılmıştır. Vercel üzerinde anında yayına alınabilir.
